# 升级与可携带成果

共享Skill与用户资料分开。更新包只替换Skill目录中的已知文件，不能覆盖用户工作区、个人规则和成果。安装前检查同名目录，保留旧版本；不要为升级删除他人的Skill或改全局配置。

分别记录Skill版本、岗位参考、企业规则、模型、工具与格式版本。变更后按依赖复查，有影响才重做相关验证。不要将其他宿主或旧模型的成功结果复制为当前通过。

原9契约作为legacy-v1保留。workspace.json是新的workspace_index附属索引，不取代旧project_state。遇旧契约先读取原schema；需要迁移时列明字段映射、保留原文件、输出新文件并验证角色、阶段、来源和未知值没有丢失。本工具不提供自动旧契约迁移；不支持的索引版本明确拒绝，不能静默解释。

当前format_version=1的升级可替换Skill副本后重读同一工作区；先保留备份、产物哈希及用户修改，验证新会话继续。索引写入原子替换，文件结果和索引不是跨文件事务；中断后重新核对结果是否入账，不能自动覆盖未登记文件。

携带个人方法时剔除雇主资料、客户信息和内部政策，只有有权保留的内容可导出。新企业规则重新确认，不把过去制度自动变成当前标准。删除、停用和撤回的影响传播到派生结果，永久删除按保留责任处理。

结果交接给没有Skill的人也应可读：任务目标、当前对象/版本、证据位置、成果、缺口、接受条件、下一步与反馈位置。不要附整段无关会话或全库敏感资料。
