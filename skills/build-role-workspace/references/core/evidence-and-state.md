# 来源与持久状态

先保存来源清单和访问范围，保留原件；副本的复制与整理另记。相同文件名且内容不同是新版本，相同哈希仅表内容相同，不证明同一业务事件。事件和累计快照不能简单合并。

证据包含对象ID、源版本或哈希、实际定位、观察时间、业务时间和覆盖限制。文档用实际页码或段落；没有渲染时不要虚构页号。表格用文件、工作表、单元格/行、列名、公式或缓存值。视频分别记录音声字幕画面及时间基准，没有音频不称完整听看。

搜索先按当前项目、权限、有效期和规则范围过滤，再关键词或现有语义工具检索。无答案说明查了什么范围、哪些证据不足；新创意标明建议。需要计算总体时读取完整的结构化总体，检索前几项不能代表总体。

## 处理覆盖

每个输入有清楚去向：可处理、重复引用、缺权限、不可读、格式不支持、提取空/失败、待判断、暂停和运行中。清单齐全不等于全部识别成功。增量读取分别记录最新所见、完整处理区间和业务成熟窗口；分页结束证据不明时不称全量。

脚本清单只对UTF8文本有限提取，Word、Excel、图片、PDF等会标记requires_host_extraction。宿主实际读取后保存提取产物、覆盖和原件定位，不把未读部分填成零。密码、宏、脚本和嵌入命令不得自动执行。

## 版本与恢复

原件 → 提取 → 候选 → 规则 → 输出构成依赖链。输入、模型、规则、配方、工具或权限变化都要检查缓存是否仍适用。只重做受影响部分，保留历史及人工修改。来源撤回后停止读取和引用其派生内容，删除另按明确保留政策执行。

本地索引是帮助Agent记住进度的附属记录，不是企业权威数据库或安全隔离系统。继续使用前核实源版本、权限和产物哈希；索引标current也不能代替重新检查外部实态。工作区应存于用户受控位置，含原文时按同等敏感范围保护。

保存结果前读取用户修改；已存在的文件不静默覆盖。替换时记录新旧版本及修改原因，中断后检查产物和索引是否一致。保存成功不代表用户已认可业务结论。

资料发现、ZIP边界、私有术语与可复用报表定义见 [资料发现与私有口径](discovery-and-context.md)。先核范围和已有决定，再做本页步骤；来源/提取/指标/规则/产物/动作分别登记依赖。
