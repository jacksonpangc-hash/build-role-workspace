# 发现实际工具并提供退路

从任务推导所需能力，先检查宿主已提供工具，再做无副作用小范围读取。区分未提供、未连接、无目标资源权限、格式不支持及暂时故障。连接状态、访问范围、动作授权、执行结果和业务正确分别核验。

记录任务/步骤、实际工具名和版本、格式/大小限制、身份和数据范围、费用、目的地、副作用、查询/取消办法、核查时间及证据。不要存令牌或密码。证据分级为P0设计需要、P1官方文档、P2本环境存在、P3样本实测、P4选定流程端到端验证，升级基于证据且可以降级。

缺工具时说明具体影响与最少用户动作，例如导出指定报表；先完成独立部分。使用当前正式接入说明与宿主安全登录，不让用户在聊天贴密钥，不为运行一个任务安装所有候选工具。无语义工具就报告限定关键词搜索，无ASR就用已有字幕并说明缺口。

## 按业务选择能力

素材需要实际多模态与时间定位；财务需要精确表格与定点计算；运营/分析需要完整导出、粒度对齐；客服/销售/HR需要身份、适用政策和草稿；采购/仓储需要单据与事件时点；项目/IT需要基线、版本和逐步证据。按需引导，不按品牌强推平台。

工具写操作须查看实际副作用。“创建草稿”可能触发通知、审批共享或记账，不能只按名字断定低风险。真实接口应核分页、默认字段、频限、版本、比较更新、幂等期限和返回值的语义。提供者文档不证明当前账户具备能力。

本发布候选的辅助工具无网络与外部执行器，支持当前Python文本文件路径。宿主的Excel、Word、PDF、音画能力按当前环境单独验证。跨宿主兼容只写实测范围，模型名称不是工具能力证明。

资料发现、ZIP边界、私有术语与可复用报表定义见 [资料发现与私有口径](discovery-and-context.md)。先核范围和已有决定，再做本页步骤；来源/提取/指标/规则/产物/动作分别登记依赖。
