# 从这里开始

这是一个通用岗位资料助手。你可以直接选要完成的工作：

| 想做什么 | 可以交付的文件 |
| --- | --- |
| 看销售、广告或财务数据 | 复盘、差异表、改进建议、备货情景 |
| 推进项目 | 计划、周报、待办、验收和交接包 |
| 处理行政、人事或客服资料 | 登记表、适用规则核对、回复草稿、未决清单 |
| 准备内容和素材 | 脚本、拍摄包、参考索引、版本差异 |

告诉助手目标和获准的资料位置，例如：

> 帮我把这个项目的进度、未完成事项和交接整理清楚，保存一份接手人能用的成果。资料没有就标出缺口，不重复索要。

助手先完成当前任务，再把确认过的定义、来源、方法和你的修改保存在私有工作目录，供下次继续使用。无需先学岗位分类或设计知识库。

成果应完整回答你的目标，先给简短结论，详细依据另存。你可以直接说“这里不对”或“从上次目录继续”。真实发送、付款、账号修改及专业批准分别核验，文件完成不代表这些动作已经做完。
