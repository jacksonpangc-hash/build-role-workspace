# 岗位知识库助手怎么用

你提供工作目标和可以读取的资料，助手先查文件，再交一份能使用的成果，并保存依据、缺口和进度。

## 能完成哪些工作

这是同一个通用Skill的不同工作方向。销售与备货只是其中一类；还可以做项目计划/周报/交接，行政合同登记/附件核对，财务差异表，客服多诉求回复草稿，脚本拍摄包和素材版本检查。按当前资料交具体成果，再保存可复用的来源、定义和方法；不会仅因生成文件就把真实业务动作或专业认可标完成。

## 第一次说什么

可以直接说：

> 这个文件夹是我授权的资料。帮我核这份费用有没有重复，保存结果。没有的资料说明即可，不用让我先填整张表。

也可以说“把交接事项整理出来”“给我一份能拍的脚本”或“根据订单做本月复盘”。岗位和月份已经说过，就不重复问。目标不清楚时，助手可从资料提出少量能做的成果供你选择。

结果先完整覆盖你提出的核心问题，再说明发生了什么、建议先做什么、为什么。摘要和详细依据分开，“一个主要行动”不等于把整个任务缩成一个局部异常；不需要先学会技术词。

## 看不懂、有错、想继续

说“只留最重要的一件事”“这里不对”或“保留我改的这一句，再重算”。助手应回到来源核查，不凭你的纠正就改写正确原件；修订保留旧版和人工修改。

下次提供同一个私有工作目录，说“从这里继续”或“做上次那份”。助手先读保存的定义和资料版本，不能只凭旧聊天说已经恢复。资料变了只重做受影响部分；重算报告不会重发采购、退款或消息。

“未知”表示暂时算不出来，不是零。缺实际库存、购买件数或成本时，可以先交有依据的部分，不能编采购量和利润。工具读取失败应说明处理到了哪里，保留可继续的结果。

## 安装

将安装包交给当前支持Agent Skills的助手，请它核对SHA256校验值，安装到一个新的、受支持的项目或个人技能位置。已有同名目录先保留，不直接覆盖；其他Skill不改。

安装包内有主入口、中文开始页、使用说明、兼容说明、许可和必要资源。更新后在新会话确认能找到并使用 `$build-role-workspace`；仅解压成功不等于宿主已经发现。Codex个人目录常用 `~/.codex/skills/`，项目位置依当前宿主支持方式。是否使用个人位置由你的安装范围决定。

辅助脚本是可选的，要求Python 3.10+且仅用标准库；没有Python时先用宿主已有工具，不强制安装全套依赖。Excel、PDF、图片、音画的读取能力先用小样实测；工具名出现不等于读成功，不把字幕/抽帧当完整听看。

## 资料、权限和费用

原件、公司规则、报告和进度保存在使用者自己的工作目录，不随共享Skill打包。公司之间的同名政策分开使用；工作目录的实际访问权限由宿主管理，本工具不是企业权限系统或安全删除服务。

整理文件、生成草稿、发送消息、修改业务系统、付款和持续运行是不同事情。文件记录齐全或模型说“完成”，不能代替实际回证与有权者认可。当前辅助工具没有外部执行器和后台调度器。

Skill原创内容采用免费MIT。模型和另外接入的工具使用宿主账号额度及相应计费方式；未知费用不填零。源码里的模型评估脚本只在开发者主动选择时调用已登录Codex，不在普通任务、导入或打包时自动启动。

## 升级、回退和卸载

先备份旧Skill和私有工作区。校验新包，放到新目录；旧定制先比较再合并。当前workspace索引仍为v1，新增records是附属文件，九份旧契约未静默迁移。

回退应保留新增定义、报告与历史。旧版不具备新版的撤回和时序检查，不应据旧版继续有风险的业务流程；兼容读取与本地恢复演练不等于生产回退放行。

卸载只移除自己安装的目录，私有工作区保留。有个人定制先归档；同名副本可能还在其他位置，不能误删。若曾另行启用外部任务，应在真实宿主取消并核回证，删Skill不会自动停止它们。

## 常见问题

找不到入口：检查安装位置并开启新会话，显式使用 `$build-role-workspace`。搜索不到：先核授权范围、压缩包成员、格式和版本，再扩同义词；一次无命中不等于资料不存在。保存冲突：先读人改内容再合并。外部结果未知：先查询，不重复提交。
